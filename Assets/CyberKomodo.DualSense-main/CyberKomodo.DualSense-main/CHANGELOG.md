## Changelog

### [v1.0.0] - 2026-05-08
- Initial release
- USB and Bluetooth transport support
- Adaptive trigger effects: Off, Feedback, Weapon, Vibration
- RGB lightbar color control - `SetLightBarColor`
- PS5 player light control - `SetPlayerLight`
- Rumble emulation - `SetMotorSpeeds`
- Backwards compatible with Unity's default `DualSenseGamepadHID` implementation
